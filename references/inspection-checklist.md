# 检查员清单

每项都要对照原图，写明“已查”“有差异”或“没查”。没有实际看过的，不能写“已查”。

## 校准
- [ ] 控制点分布在全图，而不是集中在一处
- [ ] 已报告平均误差和最大误差

## 可见线（最容易漏）
- [ ] 每个视图的轮廓线
- [ ] 不属于剖面填充边界的线，例如端面线和孔的轮廓
- [ ] 虚线、点划线、中心线和细实线
- [ ] 每条中心线的起止位置，不凭对称性补画
- [ ] 没有原图不存在的线

## 圆形视图
- [ ] 每道圆弧的半径都已实测，并和标注对照
- [ ] 每道圆弧的线型都逐条确认，不同视图不互相套用
- [ ] 凸台、圆角和圆弧的连接关系与原图一致

## 尺寸
- [ ] 文字总数和抄录一致，逐条核对
- [ ] 公差上下偏差没有写反
- [ ] 每个尺寸的指向和箭头方式（内箭头、外箭头、半尺寸）一致
- [ ] 引线走向和文字位置一致，移动过的已列出
- [ ] 尺寸链闭合，不同视图互相印证
- [ ] 量取关键尺寸，几何和标注一致；扫描件比例不符的已向用户确认

## 符号
- [ ] 粗糙度：位置、尖端朝向、长边方向、文字方向
- [ ] 几何公差和基准：符号、数值、引线目标

## 文字和标题栏
- [ ] 技术要求逐字一致
- [ ] 标题栏的行列划分和内容一致
- [ ] 尺寸数字没有被图线穿过

## 文件
- [ ] PDF 没有嵌入图片，幅面和比例正确
- [ ] DWG 转回 DXF 后，实体数量和文字一致
- [ ] 是否在 AutoCAD 等软件里实际打开过，如实写明

## 交付判定
- 差异清单已清空，且没有待确认项目：可以称为定稿。
- 还有待确认项目：必须明确写“这不是定稿”，并列出缺少的内容。
